# Installation Guide

Get up and running with AI-assisted Klever development. Choose the setup method that best fits your needs.

## Setup Options

### [Quick Setup](/using-ai-on-kvm/ai-environment-setup/quick-setup)

**Recommended for most users**

Get started in minutes using NPX or the [public hosted server](https://ai.klever.org). No cloning, building, or local setup required.

**Supported IDEs**:
- Claude Code
- Visual Studio Code (with GitHub Copilot)
- Claude Desktop
- Cursor

[Get started with Quick Setup →](/using-ai-on-kvm/ai-environment-setup/quick-setup)

### [Run Locally](/using-ai-on-kvm/ai-environment-setup/run-locally)

**For developers who need local control**

Clone and build the MCP server locally for development, debugging, or custom modifications.

**Requirements**:
- Node.js 18 or newer
- Git
- Basic terminal knowledge

[Set up local development →](/using-ai-on-kvm/ai-environment-setup/run-locally)
