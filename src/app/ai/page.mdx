# AI-Assisted Development

Use your preferred AI editor with the Klever MCP server for smart contract development.

### What you can do

- Write Rust/WASM smart contracts with Klever-aware code generation
- Deploy with generated `koperator` scripts
- Query live blockchain data directly from your editor
- Catch common mistakes before they reach the compiler
